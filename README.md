# 字节跳动 Java 后端面试训练台

面向 3 年 Java 后端经验、目标 2-1 或 2-2 的离线复习站点。

## 使用方法

直接双击 `index.html`，或在当前目录执行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

学习状态保存在浏览器 localStorage 中。不同浏览器之间不会自动同步。

## 文件

- `index.html`：完整学习内容和页面结构。
- `styles.css`：响应式布局、深浅色和打印样式。
- `app.js`：导航、掌握度、答案展开和本地进度。
- `docs/design.md`：经过确认的设计说明。

## 内容真实性

项目章节只把用户明确说过的内容标为已确认事实。模型补写的数字和实现细节都标为待核实，面试前必须逐项确认。
