# 字节跳动 Java 后端面试训练台

面向 3 年 Java 后端经验、目标 2-1 或 2-2 的离线复习与训练站点。

## 使用方法

先打开 `review.html` 系统复习，再进入 `index.html` 闭卷训练。也可在当前目录执行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

学习状态保存在浏览器 localStorage 中。不同浏览器之间不会自动同步。

## 文件

- `review.html`：16 章分层复习册与跨章节知识路线。
- `review.css`：复习册的响应式、深浅色和打印样式。
- `review.js`：复习册目录、主题和打印交互。
- `index.html`：闭卷问题、学习计划和项目训练台。
- `styles.css`：训练台基础样式与共享主题变量。
- `app.js`：训练台导航、掌握度和本地进度。
- `docs/design.md`：经过确认的设计说明。

## 内容真实性

项目章节只把用户明确说过的内容标为已确认事实。模型补写的数字和实现细节都标为待核实，面试前必须逐项确认。
