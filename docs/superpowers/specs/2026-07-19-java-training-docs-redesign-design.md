# Java 面试训练台技术手册化重设计

## 目标

把现有展示感较强的训练台改造成适合长期复习的技术手册。页面应简洁、稳定、易扫描，降低模板化卡片、徽章和装饰图形带来的 AI 生成感。

## 设计判断

这是一次保留内容与功能的视觉重设计。使用者是每天投入约一小时备战 Java 面试的开发者，页面首先服务于阅读、检索、回忆和进度记录，不承担营销展示任务。

设计参数：

- 变化度：4/10。结构清晰，允许少量非对称布局，但不追求视觉奇观。
- 动效：2/10。只保留悬停、展开和操作反馈。
- 信息密度：6/10。内容丰富，但通过层级和留白降低压迫感。

## 保留范围

- 保留所有知识模块、题目、答案、项目材料和官方资料链接。
- 保留现有锚点 ID，避免目录链接失效。
- 保留掌握度选择、本地进度、主题切换、打印、目录抽屉和今日训练逻辑。
- 保留亮色与暗色主题，默认继续尊重系统设置。
- 保留桌面端侧边目录和移动端单栏布局。

## 信息架构

页面从三栏改成两栏：

1. 左侧固定目录，承载目标画像、章节导航和使用规则。
2. 右侧正文，承载总览、诊断、计划、知识模块、项目材料与资料来源。

原右侧训练栏删除。其中“今日训练”合并到首屏，“回答结构”和“清空进度”移动到更接近使用场景的位置。桌面正文宽度限制在舒适阅读范围，宽屏不无限拉伸。

## 首屏

首屏不再使用中心节点连线图。改为技术文档首页：

- 一个直接标题：Java 面试训练台。
- 一句功能说明，控制在一行到两行。
- 两个入口：继续今日训练、查看八周计划。
- 一组真实个人信息：三年经验、目标级别、每周投入。
- 扁平知识索引，按基础、工程、架构、表达四组展示模块。

首屏在常见笔记本视口内显示主要入口，不使用渐变、光晕、漂浮节点和装饰性状态点。

## 视觉系统

### 色彩

- 使用统一的冷灰中性色。
- 全页只保留一个低饱和深蓝强调色，用于链接、焦点和选中状态。
- 成功、警告、风险色只在有真实语义时出现，不作为装饰。
- 不使用渐变背景、发光效果和大面积彩色填充。

### 字体

- 标题与正文使用 macOS 和中文系统无衬线字体。
- 代码、级别和技术参数使用系统等宽字体。
- 标题依靠字号、字重和间距建立层级，不使用花体或混搭字体。

### 形状与层级

- 正文分组主要依靠留白和单条分割线。
- 圆角仅用于按钮、展开控件和需要明确边界的小型交互区域，统一使用 8px。
- 删除大多数阴影；只允许浮层、移动端目录和提示消息使用轻阴影。
- 减少卡片嵌套，不为每段文字增加独立容器。

## 主要组件调整

### 顶栏与目录

- 品牌区域从彩色字母方块改为纯文字标识。
- 顶栏保持单行，进度和主题操作弱化处理。
- 目录当前项使用左侧强调线或浅色背景，不使用徽章堆叠。
- P0、P1 保留为真实优先级信息，但降低视觉权重。

### 诊断与计划

- 诊断从四张彩色卡片改为一个主结论和三条风险清单。
- L1-L4 使用紧凑定义列表，不使用四等分仪表盘。
- 八周计划改为清晰的周次列表，突出本周主题与训练产出。
- 每日节奏使用一行时间分配，周末说明独立放置。

### 知识模块

- 模块标题、学习目标和掌握度位于同一清晰层级。
- 掌握度改为紧凑分段控件，保持键盘可用和选中状态明确。
- 高频知识点使用扁平分组，不使用重复阴影卡片。
- 闭卷题保持 `details` 交互，问题和答案之间通过排版区分。
- 代码块继续使用深色代码背景，因为它表达真实内容层级。

### 项目与资料

- 已确认事实与待核实内容继续有明确语义差异。
- 不新增任何未经用户确认的性能数字或技术实现。
- 官方资料按技术域分组，链接样式统一，不制作三张等宽卡片。

## 响应式与可访问性

- 768px 以下改为单栏，侧边目录使用抽屉。
- 所有按钮在桌面端保持单行，触控区域不小于 40px。
- 亮色与暗色主题均保证正文、辅助文字和按钮对比度。
- 保留跳转正文、焦点样式、语义标签和 `aria` 状态。
- 不使用依赖动画才能理解的信息，尊重减少动态效果设置。

## 验收标准

- 首页不再出现悬浮知识节点、渐变、光晕或大面积彩色卡片。
- 页面只有一个强调色，正文内容以留白和分割线组织。
- 桌面端导航单行，首屏主要入口在 720px 高视口内可见。
- 390px 宽手机无水平滚动，目录可以正常打开和关闭。
- 掌握度、主题、本地进度、答案展开、打印和今日训练功能可用。
- 所有内部锚点有效，控制台无错误，JavaScript 语法检查通过。
- 页面可见文本不包含长破折号或模板化占位文案。
- 不改变任何知识结论和项目事实边界。

## 不在本次范围

- 不新增登录、云同步、题库后台或服务端。
- 不调整知识体系与训练周期。
- 不引入前端框架、组件库、动画库或网络字体。
- 不创建与学习无关的插画和摄影素材。
