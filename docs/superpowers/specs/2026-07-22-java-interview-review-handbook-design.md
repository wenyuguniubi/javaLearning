# Java 后端面试分层复习册设计

## 目标

为字节跳动 Java 后端工程师面试准备一份独立的 HTML 复习册。使用者先通过复习册理解和串联知识，再进入现有训练台闭卷答题。目标职级为 2-1，冲刺 2-2；使用者有三年 Java 后端经验，每周平均投入约七小时。

复习册负责讲解与复习，训练台负责检验与追问。两者不重复承担同一职责。

## 内容基线

- Java 8 作为高频基础原理和生产项目语境。
- Java 17 与 Java 21 补充现代语言、运行时和并发能力。
- Spring、MySQL、Redis、Kafka 等内容说明版本相关边界，不把某一版本实现描述成永久结论。
- 技术结论优先依据 OpenJDK、Spring、MySQL、Redis、Kafka 等官方文档。
- 字节内部职级和题库不是公开标准，页面只说明训练目标，不声称掌握内部评分规则。

## 页面关系

新增三个文件：

- `review.html`：完整复习内容与语义结构，先加载现有 `styles.css`，再加载 `review.css`。
- `review.css`：只补充复习册专用布局和可视化样式，不重复定义训练台已有的颜色、字体和基础控件。
- `review.js`：主题切换、移动端目录和章节定位，不承担题库或复杂状态管理。

修改现有 `index.html`，增加进入复习册的明确入口。复习册顶栏和各章结尾提供进入训练台及对应章节的链接。

## 双索引结构

### 技术栈主目录

正文按技术栈组织，保证覆盖完整和长期查阅：

1. 使用方法与复习计划
2. Java 语言与对象模型
3. 集合、泛型、异常、反射与 IO
4. Java 17/21 现代特性
5. JVM、类加载、GC 与内存排障
6. JMM、锁、AQS、线程池与异步编程
7. Spring、Spring MVC、Spring Boot 与 MyBatis
8. MySQL 索引、执行计划、事务、锁、日志与复制
9. Redis 数据结构、缓存、高可用、Cluster 与分布式锁
10. Kafka、RocketMQ 与消息可靠性
11. TCP、HTTP、Linux、IO 多路复用与 Netty
12. RPC、服务治理、配置、幂等与分布式事务
13. 稳定性、可观测性、发布、容量与容灾
14. 系统设计方法与典型系统
15. 算法模型、Java 编码模板与复杂度
16. 项目深挖、简历追问、STAR 与行为面

### 场景复习路线

首页提供四条跨章节路线：

- 一次请求：网络、网关、线程、Spring、数据库、缓存和响应。
- 性能问题：指标、CPU、GC、线程池、SQL、缓存和下游容量。
- 稳定性问题：超时、重试、幂等、消息、隔离、限流、降级与恢复。
- 系统设计：需求、估算、模型、接口、架构、可靠性和演进。

每条路线只承担导航与串联，不复制章节正文。

## 每章固定层次

### 10 分钟速读

列出本章必须掌握的结论、关键术语、核心关系和复习顺序。内容适合时间不足时快速扫读，但每条结论必须准确说明适用边界。

### 深入原理

通过文字、流程、时间线、对比表、数据结构示意和短代码解释机制。重点回答“为什么”和“如何验证”，不堆砌 API 名称。

### 易错点与工程边界

集中纠正常见错误表达，例如把频繁 Full GC 直接等同于内存泄漏、把无索引查询简单描述为表锁、把 `acks=all` 描述为绝对不丢消息。

### 训练入口

章末列出完成复习后的验收目标，并链接到训练台的对应模块。复习册不直接展示训练台的参考答案。

## 内容表达规则

- 使用通俗中文解释，首次出现术语时说明含义。
- 先给结论，再解释机制、场景和边界。
- 一段只解决一个问题，长内容拆成小节。
- 代码只保留能说明机制的最小片段。
- 不虚构项目指标、公司内部实现或面试题来源。
- 标明版本相关、实现相关和业务取舍相关的内容。
- 项目章节严格区分已确认事实、待核实数据和建议表达。

## 视觉与交互

- 延续训练台的冷灰技术手册风格、系统字体和单一深蓝强调色。
- 桌面端使用左侧目录与右侧正文，正文限制在舒适阅读宽度。
- 移动端使用单栏正文和目录抽屉。
- 内容主要用留白与分割线组织，卡片只用于真正独立的提醒或语义状态。
- 流程、依赖、时间线和对比关系使用原生 HTML/CSS 可视化，不绘制装饰性概念图。
- 支持亮色、深色、打印和键盘操作。
- 不使用渐变、光晕、浮动节点、自动动画或外部网络字体。

## 脚本职责

`review.js` 只实现：

- 跟随系统、亮色、深色三态主题切换。
- 移动端目录打开、关闭和 Escape 退出。
- 使用 IntersectionObserver 标记当前章节。
- 打印复习册。

不增加登录、云同步、章节打卡、题库评分或服务端逻辑。

## 验收标准

- 16 个章节均包含速读、深入原理、易错点和训练入口。
- 四条场景路线能跳转到正确章节。
- Java 8 基础与 Java 17/21 补充有明确边界。
- 与训练台双向链接有效，原有训练功能不受影响。
- 所有内部锚点有效，没有重复 ID。
- 1280×720 桌面端导航和首屏入口清晰。
- 390×844 手机端无水平滚动，目录可打开和关闭。
- 亮色和深色主题文字对比度满足 WCAG AA。
- JavaScript 语法检查通过，浏览器控制台无错误。
- 可打印，展开内容不会在打印时丢失。
- 页面不出现长破折号、占位文案、虚构数字或模板化营销文案。

## 不在本次范围

- 不复制训练台的 60 组闭卷题与参考答案。
- 不新增视频、图片素材、第三方组件库或前端框架。
- 不创建后台、账号体系、在线编辑或远程数据存储。
- 不承诺覆盖目标团队未公开的内部面试题。
