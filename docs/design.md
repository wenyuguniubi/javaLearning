# 设计说明

## 目标

为 3 年 Java 后端经验、计划在 1-3 个月内面试字节跳动 Java 后端岗位的候选人提供高可视化、可离线使用的复习与训练站点。训练目标是稳过 2-1，并通过系统设计、项目深挖和工程判断冲刺 2-2。

## 已知背景

- 有信用卡分布式核心系统和信用卡前置系统经历。
- 负责信用卡授权部分、性能优化、慢 SQL、缓存、容器 OOM、流水线和信创相关工作。
- Java、JVM、并发、MySQL、Redis 已形成过总结，但仍需闭卷验证。
- MQ、Spring、网络和陌生系统设计需要优先补强。
- 项目中由模型补写的数字和实现不能视为事实。

## 信息架构

站点采用面试训练台布局：

- 左侧为完整目录和模块状态。
- 中间为通俗讲解、知识结构、原理图、对比表和闭卷追问。
- 右侧为今日训练建议和回答结构。
- 首页知识地图连接 Java、JVM、并发、Spring、存储、MQ、分布式、设计和项目。

## 学习交互

- 模块掌握度使用 L1-L4。
- L3 代表能够承受连续追问，L4 代表能够结合项目落地。
- 进度和主题设置保存在浏览器 localStorage。
- 高频问题先显示题目，答案通过 details 折叠。
- 打印模式展开答案并隐藏导航与交互控件。

## 内容优先级

- P0：算法、项目真实性、Java、JVM、并发、Spring、MySQL、MQ。
- P1：Redis、网络、Linux、分布式、系统设计和行为面。
- P2：用于补充广度的低频细节。

## 八周计划

1. 闭卷定级、Java 基础、JVM。
2. 并发、线程池、Spring。
3. MySQL、Redis。
4. Kafka、RocketMQ、网络、Linux。
5. 分布式、微服务、稳定性。
6. 系统设计、容量估算。
7. 项目深挖、行为面、薄弱项。
8. 高频复测与全真模拟。

平均每天投入约 1 小时。建议 15 分钟间隔复习、25 分钟核心知识闭卷学习、20 分钟输出训练。周末增加算法、故障题或系统设计和模拟面试。

## 真人模拟面试

模拟在 Codex 对话中进行，不由静态网页替代。单题按正确性、深度、工程性、表达和职级表现评分，每项 0-4 分。

- 2-1 训练通过线：核心题平均至少 14/20，无明显否决项。
- 2-2 训练候选线：平均至少 17/20，项目和系统设计稳定达到 18/20。
- 最终标准：连续三轮综合模拟达到目标线。

以上分数是训练标准，不是字节跳动官方评级规则。

## 技术约束

- 使用原生 HTML、CSS 和 JavaScript。
- 不依赖构建工具、前端框架、后端或数据库。
- 同时支持深浅色、移动端、键盘操作、减少动效偏好和打印。
- 不获取或上传任何非公开银行代码。
- 只向目标 Git 仓库上传本项目文件。
